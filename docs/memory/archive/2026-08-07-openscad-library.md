Project is an OpenSCAD drawing library for 3D printing. Each drawing is a single .scad file with parameters at the top, a named module, and a preview PNG generated via openscad CLI. Reference docs at en.wikibooks.org/wiki/OpenSCAD_User_Manual. All file and directory names use kebab-case.
