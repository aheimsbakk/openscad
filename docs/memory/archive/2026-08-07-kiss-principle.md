All solutions in this project follow the KISS principle (Keep It Simple,
Stupid): prefer the simplest solution that meets the stated requirement, and
justify any added complexity. KISS does not override the contracts in
BLUEPRINT.md and CODEBASE.md. Per user rule, decisions and ADRs are kept only
in this memory system (docs/memory/), never as ADR files in the repository.
